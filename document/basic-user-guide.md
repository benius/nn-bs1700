# CulinaForge 入門使用者指南

CulinaForge 會依你指定的一個或多個烹調設備 Skill，把現有食材整合成指定人數與餐點名稱的專屬食譜。每個 Skill 只負責一台設備；當提示中指定多個 Skill 時，agent 會安排設備分工、先後順序與可平行進行的步驟。

## Skill 名稱前的符號

下列範本採 Codex 的 `$skill-name` 寫法。Claude Code 或 Copilot CLI 可能使用 `/skill-name`；Gemini CLI 與其他 agent 可改成自然語言，例如「請使用 cooking-with-nn-bs1700 與 cooking-with-rb-2232h」。詳細差異請見各平台使用指南。

## 食譜提示範本

```text
我有下列食材，推薦我使用 $<agent skill name 1> 與 $<agent skill name 2> 做一道 <實用人數> 人份的 <餐點名稱>：

1. <食材名稱 1> <份數> 份，每份 <重量> g/kg
2. <食材名稱 2> <份數> 份，每份 <重量> g/kg
3. <列出所有食材，格式如上 1>

特別說明：
<說明偏好或者指定的食材料理方式>
```

只用一台設備時，保留一個 Skill 名稱即可。食材沒有重量時可以只寫包數、顆數或份數；agent 會依一般情況判斷合理份量並明列假設，不需要先停下來追問。

## 完整範例

```text
我有下列食材，推薦我使用 $cooking-with-rb-2232h 與 $cooking-with-nn-bs1700 做一道三人份的咖哩飯：

（食材沒有說明重量時，則依據一般情況自行判斷）

1. 冷藏飯兩包，每包 170g
2. 義美冷凍花枝丸 4 顆
3. 鴻禧菇一包
4. 蒜頭 10 瓣
5. 咖哩雞肉調理包兩包，每包 200g
6. 冷藏雞腿肉一隻 400g（帶骨）
7. 山藥 200g

特別說明：
我想要先將冷藏雞腿肉去骨剪小塊再料理，不確定是否合適，你再幫我推薦做法。
我想要將咖哩雞肉調理包剪開，先將咖哩雞肉倒在鍋中，跟其他的食材一起料理。
```

## Agent 應提供的內容

一份完整結果應包含：

1. 人數、餐點目標、食材總量與所有重量假設。
2. 食材是否需要解凍、去骨、分切、分批或延後加入。
3. 每台設備負責的食材與步驟，且每個設定都由對應 Skill 支持。
4. 可平行進行的時間線，以及最後組合、調味與上桌順序。
5. 各設備的模式、功率或火力、容器、配件、層位、預熱、首輪時間與檢查點。
6. 食品安全與完成判定，以及未熟、過濕、不夠上色或濃度不符時的補救方式。
7. 哪些數值來自設備手冊或實測資料，哪些只是食譜設計的合理估算。

若你的指定做法不適合食材、設備或食品安全，agent 應說明原因並提供能保留原意的替代做法。

## 輸出檔案

在 CulinaForge repository 內要求產出食譜卡時，Markdown、PDF 與 PNG 都放在 `output/recipe-card/`，暫存檔只放在 `tmp/`。

第一次使用餐點名稱作為檔名；若任一同名目標已存在，不覆蓋舊檔，三種格式改用同一個時間戳記：

```text
<餐點名稱>-yyyymmdd-hhmmss-.md
<餐點名稱>-yyyymmdd-hhmmss-.pdf
<餐點名稱>-yyyymmdd-hhmmss-.png
```

例如：`番茄海鮮速拌細麵-收乾版-20260804-180559-.png`。

需要依使用手冊建立新設備 Skill，或想進一步控制來源與多設備分工，請閱讀[進階使用者指南](advanced-user-guide.md)。
