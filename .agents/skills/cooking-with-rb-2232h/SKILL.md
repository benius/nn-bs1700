# 台灣林內 RB-2232H IH 智慧感應爐

## 來源與設備邊界

只使用本 Skill 的 `references/` 內嵌文字核對 RB-2232H 的設備事實。這些文字只保留《IH 智慧感應爐使用說明書》（2021.05）中適用 RB-2232H 的內容。不要以一般 IH 爐經驗、網路資料、其他機型說明書或自行推算補足原文沒有提供的設備設定。

本 Skill 不回答其他機型的比較問題。涉及爐口時明確指出左爐或右爐；來源表格若有其他機型欄位，視為不在本 Skill 範圍內，不得引用。

本 Skill 只提供 RB-2232H 的面板操作、火力、功率、鍋具、限制與安全資訊。不要提供 NN-BS1700、瓦斯爐、電子鍋或其他設備的設定，也不要把其他設備時間換算成 RB-2232H 火力。

## CulinaForge 食譜協作

說明書只提供食物類別的參考火力，沒有具名食譜。單獨詢問設備時，原文沒有時間、水量、油量、食材處理或完成判定就寫「說明書未提供」。

使用者以 CulinaForge 食材範本要求完整食譜時，允許主 agent 用一般料理知識設計切法、下料順序、水量與首輪時間，但必須遵守：

1. 把 RB-2232H 的火力、Booster、雙爐、鍋具與安全限制稱為「說明書設定／限制」。
2. 把手冊未提供的時間、水量、油量、食材處理與完成判定稱為「食譜設計／合理估算」，不得歸因於說明書。
3. 多個設備 Skill 同時啟用時，只負責 RB-2232H 的步驟；其他設備由對應 Skill 提供設定，主 agent 合併時間線。
4. 不為了使用 RB-2232H 而加入沒有必要的步驟；若另一設備更適合，可明說本爐不參與該段。
5. 完整跨設備食譜是 CulinaForge 輸出，不得存回本 Skill 的 `references/`。

## 解析食材提示

支援指定一個或多個 `$<agent skill name>`、用餐人數、餐點名稱、編號食材清單與「特別說明」。先整理每項食材的名稱、品牌、份數、重量、保存狀態、厚度、帶骨或已調理狀態，以及使用者偏好的去骨、分切、下料順序與口感。

沒有重量時依一般包裝、顆數或份量建立合理估算並明列假設，不停下來要求補齊。包裝食品的解凍、加熱與保存指示優先；使用者偏好若和油炸、鍋具、火力或食品安全限制衝突，說明原因並提供安全替代方案。

## 回答流程

1. 確認機型為 RB-2232H；涉及爐口時確認左爐或右爐。
2. 確認是操作功能、選火力、煮飯、排除故障、清潔、選鍋、安裝，或 CulinaForge 食譜分工。
3. 從相符參考檔核對數值、顯示代碼、最長時間與限制。
4. 先給可直接照做的原廠步驟，再補同段警告與自動關閉條件。
5. 完整食譜中，把手冊設定與食譜設計值分開標示。

## 火力與料理問題

以說明書參考分類為設備依據：

- 1 段：保溫。
- 2～3 段：加熱食物、燉煮。
- 4～6 段：蔬菜、魚類、海鮮類。
- 7～9 段：肉類。
- Booster：快速煮水；最長 8 分鐘後自動降到 9 段，不可用於油炸。
- 油炸：可使用 7～9 段，待油滾依序放入食物後，再斟酌向下調整火力。

把這些數值稱為「說明書參考火力」，不要改寫成保證熟成的設定。完整食譜可以設計分鐘數與完成判定，但要標示為食譜估算，並以食材狀態、包裝指示、中心溫度、沸騰狀態或質地驗收。

## RB-2232H 機型限制

回答雙爐問題時同時交代：雙爐總功率不超過 3540 W、總額定電流不超過 16 A；一爐使用 9 段時，另一爐最高只能設到 7 段；右加熱區啟動 Booster 時，左加熱區只能設第 3 段。

RB-2232H 只有右加熱單元 IHE180P 支援 2860 W Booster；左加熱單元 IHE180 的表列 Booster 功率為「／」。安排同步食譜時間線時，必須檢查雙爐限制，不能同時給出面板無法設定的火力組合。

## 故障與安全

先處理立即風險，再列原因與原廠處置：

- 油類著火時不可灑水；蓋上鍋蓋並切斷加熱區電源。
- 面板裂痕、縫隙或破裂時，立即關閉產品、切斷電源並聯絡本公司各地營業所。
- 觸控鍵無法關閉產品時，立即切斷電源並聯絡本公司各地營業所。
- Erxx、E3、E4 或其他 Ex 持續出現時，依故障表停止操作或關機重試；需要服務時只建議聯絡本公司各地營業所，不教拆機。
- 安裝、維修與配線只轉述原文要求；電器配線須由合格電工或電器專業人員施工。

不要淡化「切斷電源」「停止烹調」「聯絡服務」等原文處置。

## 組成食譜答案

依問題需要輸出：食譜摘要與重量假設、食材準備、設備分工、鍋具與左右爐、同步時間線、各段參考火力與食譜估算時間、限制與自動行為、完成判定、補救方式及來源說明。

不要只丟一行火力數字；同時說明該數字是手冊的參考分類，以及是否受 Booster、定時器、雙爐或自動關機限制。手冊未提供的內容不可標成原廠建議。

## 食譜檔案與暫存位置

在 CulinaForge repository 產生食譜檔案時：

1. Markdown、PDF、PNG 一律寫入 repository 根目錄的 `output/recipe-card/`。
2. 渲染、轉檔、下載或測試暫存資料一律寫入根目錄的 `tmp/`。
3. 第一次使用 `<餐點名稱>.<副檔名>`。若任一同名目標已存在，不覆蓋；三種格式共用同一本地時間，改名為 `<餐點名稱>-yyyymmdd-hhmmss-.<副檔名>`。
4. 例如 `番茄海鮮速拌細麵-收乾版-20260804-180559-.png`。
5. 完成檔案不得寫入 Skill 根目錄、`references/`、`document/` 或 `tmp/`。
